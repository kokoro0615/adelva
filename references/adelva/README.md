## 事業内容

ADELVAは、ホテル・旅館を中心とする宿泊事業者の「経営実装パートナー」です。経営、現場運営、収益成長、ブランド、DX・ITを一つの改善計画につなぎ、課題把握 → 判断 → 実行・実装 → 運用 → 検証 → 引継ぎまで支援する位置づけです。

対象は「オーナー・経営者・事業責任者」と「総支配人・支配人・部門責任者」の2群で、サイト上でも同格に扱います。一部のWebサイト制作は一般事業者も対象です。サイトの目的は、訪問者が自社の課題と支援範囲を対応づけ、問い合わせフォームを送信できることです。

根拠: [事業定義・対象顧客](sources/PRODUCT.md)

## 10の支援テーマへの整理

## ウェブサイト構成（計画）

採用された情報設計は、事例1件を含む26ページ・13テンプレートです。旧36ページ案ではなく、20サービスを10テーマページに統合した構成です。事例件数Nに対してページ数は25 + Nです。

```text
/
├── services/
│   ├── management-operations/
│   │   ├── management-improvement/
│   │   ├── opening-operations/
│   │   ├── operations-improvement/
│   │   └── people-recruitment/
│   ├── revenue-brand/
│   │   ├── acquisition-sales/
│   │   ├── web-visual-production/
│   │   └── social-media-operations/
│   └── dx-it-procurement/
│       ├── system-delivery/
│       ├── it-operations-maintenance/
│       └── amenity-procurement/
├── challenges/
│   ├── owners/
│   └── general-managers/
├── approach/
├── cases/
│   └── [caseSlug]/
├── about/
├── contact/
│   └── thanks/
├── privacy/
└── site-policy/
```

グローバルナビゲーションは「課題から探す / 支援内容 / 支援の進め方 / 導入事例 / ADELVAについて」。主要CTAは「問い合わせを送信」で `/contact` に統一します。

課題別の入口は、経営・収益、開業・運営体制、現場品質・人材、集客・ブランド、DX・IT・調達の5群です。2つの対象者別ページと3領域別ページを組み合わせ、サービス名称が分からなくても探索できる構成です。

13テンプレートは、HOME、支援内容一覧、支援領域、支援テーマ詳細、課題一覧、対象者別、支援の進め方、事例一覧、事例詳細、会社紹介、問い合わせ、法務、送信完了です。フッターは10支援テーマの索引を担い、モバイルでは支援領域をアコーディオンで段階表示する設計です。

根拠: [全URL・ナビゲーション・各ページ構成](sources/information-architecture.md)
