## モーション設計案

以下は将来の実装用提案。静止画像にはアニメーションが含まれず、参考サイトの実測値でもない。

| 対象 | 動作案 | 目的・静止時の扱い |
| --- | --- | --- |
| ヒーローの建築 | スクロールに連動して写真内部のみ最大3%移動。文字とナビは最初から可読 | 建築の奥行き。長い導入や操作待ちを設けない |
| 5課題の索引 | 該当章に合わせて番号と下線を更新。クリックでアンカーへ | 一覧と現在位置の対応。スクロール中のフォーカスは動かさない |
| 章の写真 | 進入時に写真だけ450〜600msの小さなクリップ開示、cubic-bezier(.22,1,.36,1) | 01俯瞰→03現場→05素材という視点の切り替え。本文・リンクは隠さない |
| 支援リンク | hover/focusで下線色、矢印最大4pxを180msで変更 | 選択先を明瞭にし、連続操作は現在状態から応答 |
| 6工程 | 読む位置に合わせて通過部分の線を強調 | 改善の連続性。全工程は常時表示 |

モバイルは通常の縦スクロールを維持し、画像移動・複雑な開示を省略。索引の全項目へ到達可能にする。reduced-motionでは写真移動とクリップを無効化して完成状態を表示。今回はモバイル専用画像や実装を作成していない。
