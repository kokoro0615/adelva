## 納品と検証
- [最終PNG](./challenges-desktop-1440.png): **1440×5090px**、11,069,962 bytes。v4と同じキャンバス。
- SHA-256: `974ff7a1461d75d2fe46d41f7b7e1fd7b69c7997b7243bc775b5d17950104ef1`。
- [検証JSON](./verification.json)、[差し替え・検証スクリプト](./replace-photos.mjs)。
- 8写真すべて新規生成。写真枠の位置・サイズ、ページ構成、色面、本文、ナビ、番号、リンク、工程、footerはv4を使用。
- 元の画像のうち、写真用変更マスク外のRGB差分は **0画素**。見出し・CTA・重なり枠の保護画素67,242も **差分0**。
- 写真上の見出しは元の白字画素と隣接する中性のアンチエイリアス画素を保護。旧背景の輪郭を残さないよう、単純な2px拡張マスクから色条件付き1px隣接マスクへ修正した。元写真との混色済みの全エッジ画素を完全復元したとの主張ではない。
- 全アセットを元の写真枠へ等比cover配置。小画像の拡大、キャンバスのリサイズ、文字の再生成・再組版なし。元v4ファイルは未変更。
- PNGデコード後のRGBが合成バッファと完全一致。最終原寸で写真、見出し、CTA、重なり枠を目視確認。
- 本件はラスタ画像のみ。アプリ実装・ブラウザ挙動・レスポンシブ・axe・公開の検証対象ではない。

## Amanの研究範囲
[Aman公式](https://www.aman.com/)および次の公開ページと写真を読み取り・目視参照した。

- [Amangiri](https://www.aman.com/resorts/amangiri): 巨大な地形に対して建築を小さく扱うスケール、砂岩の層、斜光と影。俯瞰写真と峡谷写真を確認。
- [Amankila](https://www.aman.com/resorts/amankila): 海の水平線、前景の建築と遠景の関係、青い水面を重ねる奥行き。プール越しの海の写真を確認。
- [Aman Kyoto](https://www.aman.com/resorts/aman-kyoto): 苔、石、木々の光の微細な差、周囲の自然に溶け込む建築。庭の写真を確認。
- [Aman Rosa Alpina](https://www.aman.com/resorts/aman-rosa-alpina): 山並みの重なりと朝夕の空気。山稜の日の出写真を確認。

外部写真のコピー、Amanロゴ、施設名のUI追加は行っていない。Amanのトップはcookieパネルが表示され、動作・演出の全体を確認したとは扱わない。今回の参照は写真表現の研究でありサイト複製ではない。
