## モーション設計案

以下は将来実装する場合の提案値。画像自体は動かず、参考サイトの実測値でもない。

| 対象 | きっかけと変化 | 意図・静止時の扱い |
| --- | --- | --- |
| ヒーロー | スクロールに応じて写真内側を最大4%移動、霧の境界で紙面へ接続 | 建築の奥行き。見出しとCTAは最初から読める |
| 4局面 | hover/focusで180msの罫線色変化、矢印最大4px移動 | 選択先の識別。全項目は常時表示 |
| 判断の写真 | 章の進入時に内側のクリップを650ms、cubic-bezier(.22,1,.36,1)で開く | 全景から近景へ焦点を移す。本文は隠さない |
| 支援図 | 選択した行の接続線だけ200msで強調 | 局面・支援・判断の因果関係。全行の文字は常時表示 |
| 実行工程 | 通過に応じて6工程の線を順に強調 | 進行と引継ぎの連続性。強制横スクロール・ピン留めは不要 |
| 問い合わせ | hover/focusで色と矢印の短い変化 | 行動先を明示。演出による操作待ちは設けない |

連続入力で演出をキューに溜めず現在状態から切り替える。フォーカスを移動させない。モバイルは写真移動を省略し、複雑な図は縦に並べる。reduced-motionは移動・クリップを無効化し、すべて完成状態で表示する。
