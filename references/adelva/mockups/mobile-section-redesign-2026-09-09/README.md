## 表示・連結検証

- 全18原画の実寸をsharpで読み取り。ヒーローは両方853×1844px。幅390pxへ等比縮小した高さは843px（理論値843.095）。844pxへの非等比引き延ばしは行っていない。
- 原画はツール出力とSHA-256が全18枚一致。
- ローカル処理は幅390への等比縮小と単純な縦連結のみ。デザインのローカル描画、文字の上書き、切り抜き、重要部のトリミングはしていない。
- 完成PNGから各章範囲を再抽出し、等比縮小した各章とのデコード画素ハッシュを照合。全18枚一致。
- 完成PNGを上から844pxずつ、GM10区画（末尾20pxを含む）・OWNERS9区画で原寸表示して確認。変更後はGMの支援前半・後半、OWNERS末尾の影響範囲を再確認した。
- 同色が連続する境界と写真→本文の境界も別途確認。重複した章見出し、文字や重要な写真の切断、欠落なし。
- CTAの色領域・枠線の実寸を確認。GM実行の主要CTAは約54px高、GM末尾は約56px高、OWNERS末尾は約57px高。ヒーローの枠線CTAはGM約56px、OWNERS約52px。測定・目視の対象は描かれた矩形であり、実装上のクリック領域ではない。
- 日本語の本文は390px表示で全文を読み取り可能。原画の文字セルは箇所によって異なり、CSSのfont-sizeとして14–16pxを全ノード保証するものではない。

## 残っている具体的な差

重大なコピー欠落はないが、以下は生成画像の制約として残る。全寸法一致・ピクセルパーフェクト・WCAG適合を主張しない。

1. 「引継ぎ」「引き継ぎ」など送り仮名、欧文のスペーシング、括弧や矢印の字形に原稿と異なる表記がある。意味・条件は保持。例：両ページの工程末尾や確認項目は「引き継ぎ」で描かれた箇所がある。確定コピーはCOPY.mdを優先。
2. 左右余白は多くが24px付近だが、GM支援章では外側約35px、OWNERSヒーローでは約19–24pxのばらつきがある。OWNERS末尾CTAは約300px幅で、本文の約342px幅までは伸びていない。高さは修正で約57pxとなり、52–56px目標をわずかに超える。
3. GM現場課題・判断、OWNERS実行・検証の見出しは目標30pxより大きめの字面が残る。GM支援前半のサービス・成果物のリストは可読性を優先した拡大で他章本文より大きい。ヒーローのパンくずとGMのSCROLLなど小さな補助表記は12px目標未満の字面が残る。
4. GM実行章は希望1000pxに対し実際762px高。6工程の行間はOWNERSより詰まっているが、工程名・本文は読める。工程図に操作領域は実装されていない。GMフッターナビの描画行高は約42pxで、44px目標にわずかに届かない。
5. GM支援前半→後半、OWNERS支援前半→後半にわずかなネイビーの明度段差が見える。背景は完全な指定単色ではない。写真後のGM役割章の開始まで約128pxの白い間隔、OWNERSの経営局面→判断にも広めの間隔がある。文字の重なりや情報欠落はない。
6. ヘッダーロゴは生成による再描画。細かなシンボル形状や末尾のADELVAの字幅はページ間で完全一致していない。

この納品は閲覧・検討用の静止ラスタモック。上記の寸法差を残したまま、全数値基準を満たしたWeb UIとして完了報告するものではない。

## 画像の出自

今回の採用18枚は全てimage_genによる生成UI。建築写真は架空のホテル空間・山並み・水面で、実在顧客や実績施設の記録写真ではない。参照はユーザー指定のADELVAデスクトップと今回の採用画像。第三者の新しい写真・フォントファイル・ロゴ素材はダウンロードして組み込んでいない。Figma書き出しはresearch/内の参照限定。公開利用の権利確認は今回のモック制作範囲で追加認定していない。
