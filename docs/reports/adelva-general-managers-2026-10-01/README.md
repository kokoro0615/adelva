## 2. 変えたこと（写真・文言・章・リンクは据え置き）

朝の光が一筋、読む位置に合わせて斜面を下りる。どの場面も読むだけで色と光が変わり、タップは「その田に光を残す」追加操作として残した（03・07 への引き継ぎも従来どおり）。

- 読み込み: CSS だけで最初の描画から開始（水和を待たない）。青い時刻から明け、見出しは行ごとに見えない基線から持ち上がり、見出しの右の水面に朝日が差して引く。ちらつきは解消。
- 01: 読む位置に最も近い田だけが灯り、文字が墨に、輪が「＋」に。下へ読み進むと、光の滴が畦を越えて次の田へ渡ってから灯る（A 案の「水が上の田から下の田へ渡る」）。選んだ田には光が残る。案内文をモバイルにも表示。
- 02: ラジオを廃止し、読んでいる論点に合わせて写真の印が切り替わり、その線が描かれる（段の目盛りつき）。3つの論点の文言はすべて本文として読める。
- 03: 関係する課題のチップを常に表示（選んだ課題は橙の縁と点）。行が入ると光が走り、左の図が描かれる。
- 見出し: 章番号が左から、h2 は行ごとにマスクから持ち上がる。
- 04: 役割がそれぞれ画面に入るときに一段ずつ。05: 光の点を大きく、到達した工程名が入る。06: 罫線を光が進み、届いた項目にチェック。07: 送信後の流れが順に灯り、斜面の下の宿の窓が明るむ。
