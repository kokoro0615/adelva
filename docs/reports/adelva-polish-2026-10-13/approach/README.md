## 変更点

- **潜る＝追従ステージ（R1）**：01 の `li` をヒーローの下まで伸ばし、その中に CSS `position: sticky` のステージ（ヒーロー写真＝カメラ、夜の幕、01 の枠、窓の四辺）を置いた。止まる長さ `--dive`・止まる位置・着地位置はすべて `svh`/`lvh` の calc（ツールバーの伸縮で再計算しない：R7）。01 は着地位置にレイアウトしてあり、潜りの終わりは変形なし＝そのまま流れる。
- **進捗はコンポジタ（R2/R3）**：GSAP/ScrollTrigger を外し、Web Animations を ViewTimeline（`exit-crossing`＝止まり始め〜離れる瞬間ちょうど）と ScrollTimeline に接続。`transform`/`opacity` のみ。1 フレームあたりの JS は 0。非対応ブラウザは、潜りをステージ内のレイヤーだけ減衰進捗（τ65ms、静止で停止）で、合焦は読みの線で 0.9s の時間演出を一度。
- **窓と拡大線**：窓は枠の非等倍縮小＋中身（lens）の逆拡大。拡大線は回転した箱で、端点を変形だけで動かす（窓の角に遅れなく付く）。ペア 0 はカメラと一緒に動き、ペア 1 は着地の瞬間だけ現れる。
- **合焦の暗がり対策**：窓を写真の上寄せ（高さの 8%）から ease-out で開き、写真が 78% 入るまでに全開。潜りの夜は途中 46% までで景色を見せ、着地直前に暗転。
- **着地後**：カメラ（6.5 倍に拡大された層）は着地で非表示にし、ステージはダイブの前後 200px を越えると「止まっていた場所」と同じ位置の relative に置き換える（WebKit が解放後の sticky 箱を毎フレーム再描画していたため。切り替えは Chromium 0px / WebKit 0.5px の誤差）。
- **一度だけの表示（R8）**：画面より下にある要素だけ保留にし、読みの線で CSS トランジション（工程の文字、06 引継ぎ、範囲バー、組み合わせの例、確認の印）。ヒーローの初回（四隅・寄り・レール・線）は初回描画からの CSS アニメーション。
- **リンク**：`#stage-01`（ヒーローのファインダー、レールの 01）は潜りを通って着地点へ移る（デスクトップの Lenis でも同じ）。キーボードで 01 の中へ入ると着地させる。
- **固定レール**：現在位置は IntersectionObserver、伸びは ScrollTimeline。電話（<600px）は点をなくした細い線だけ。
- **電話の文字**：390 未満では H1・リード・節見出し・対象者リンクを 390 の比率に（`min(t, m)`）。長い 2 つの見出しは文節でだけ折る（`Lines.phrases` → `<wbr>`、`word-break: keep-all`）。確認する内容の 4 項目を同じ大きさで 1 行に（電話。デスクトップは従来どおり）。降下部の最小高さを `min(t, m)` に。組み合わせの例を 3 領域の近くへ（上の余白 93.85t → 48t）。
- 共通エージェントの依頼：`IntentLink` を使用（ルートの先読みなし）、電話のバーの blur なしを e2e で確認。

## 決定事項

- ScrollTrigger の pin と scrub をやめ、スクロール／ビュータイムライン（Chrome 115+、Safari 26+）に置き換えた。非対応時は R1 の (a)(b) に従う減衰進捗・時間演出。
- 01 の `li` がヒーローの写真を持つ構造にした（写真は装飾、`aria-hidden` 相当の空の `alt`）。ヒーローの節は文字・レール・ファインダーのリンク（同じ矩形の透明なリンク）を持つ。
- 合焦の窓は中央からではなく上寄せから開く（暗い帯の解消。承認済みの「ファインダーの形の窓が開き、写真が 1.25→1、前のファインダーが 1.08→1」は維持）。
- 潜りの途中の暗さは 46% まで（以前は 0.28 から真っ暗へ）。着地直前に暗転するのは、解放後のステージがページの地と一体に流れるため。
- 電話の固定レールは点のない細い線に（承認済みの「現在地を示す」役割は伸びで保つ）。
- 責任分界の表に縦の通し線を試したが、役割名の左端に重なるため採用せず、各行の端の目盛り（モックどおり）を残した。
- 確認する内容の見出しは電話で 4 つとも同じ大きさ（20.2m 上限）。spec §8 の「4 つ目だけ小さく」は電話では置き換え、デスクトップは維持。
- before の数値は、本番サーバー（4791）が途中で止まったため、統合ブランチを別ワークツリーで同時にビルドして取った（共通部分の改善が入った状態との比較なので、このページの変更の効果だけが出る）。
