## 3. 試作との一致（同じ場面進度、ヘッダー下を 1/4 に縮小した平均絶対差）

方法：試作 `?capture=1&static=1` の `__cap.set(y, 20)` と本番 `?capture` の `__home.frame(y, 20)`。PC は Lenis のスクロールが止まってから撮る。

| 段階                           | PC 1440×900（22〜23 場面）              | スマホ 390×844（22〜23 場面）             |
| ------------------------------ | --------------------------------------- | ----------------------------------------- |
| AA 調整の前（移植の忠実度）    | 0.0006〜0.0062                          | 0.0013〜0.0075                            |
| AA 調整の後（公開版）          | 0.0000〜0.0167（課題の冒頭のみ 0.0357） | 0.0000〜0.0229（課題の冒頭 0.033〜0.043） |
| ヒーロー（映像が分かれる途中） | 0.023〜0.025                            | 0.13                                      |

- ヒーローの差は映像の中身の違い（検証用 Chromium は H.264 を再生できず本番はポスター、試作は書き出したフレーム）。
- AA 調整の後の差は、写真の上の文字を基準に届かせるために足した陰り（仕様 §9）。課題の冒頭は、見出しの背後の陰り（試作では雪の上で白い見出しが読めなかった）。
