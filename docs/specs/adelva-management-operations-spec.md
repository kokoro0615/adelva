### 7.2 モバイル・タブレットの動き（`m.js` の移植）

画面に固定した1枚の canvas に、プレートのうち見えている範囲だけを描く。カメラはスクロール位置だけの関数。
索引は sticky の 100svh、サービスの違いは sticky の 100svh（下揃え）。光の帯・ぼかし・暖色はキャンバス内で合成する。
索引の列・瘤の輪・ラベル・光の糸だけが写真に付いて動く（transform のみ）。
`reduce` ではカメラが場面ごとに切り替わり、光の移動・夜明け・光の糸の伸びはない（最初から最終の状態）。
JS なしでは索引が2列の一覧になる。

### 7.3 アクセシビリティ（WCAG 2.2 AA）

- 見出し：h1 → h2（索引・違い・進め方・対象者・問い合わせ）→ h3（テーマ・工程）
- 縦組みの索引は `ul > li` で、DOM の読み順＝テーマ順・サービス番号順。装飾（罫・目盛り・輪・糸・canvas）は `aria-hidden`
- コントラスト：すべての文字行で 4.5:1 以上（大きい文字は 3:1）。文字の下に形の見えないぼかし（text pool）を敷く
- フォーカス：2 px オレンジの輪郭、offset 4 px。Tab 順＝ヘッダー → CTA → 進め方へのリンク → 導線2つ → 問い合わせ → フッター
- 200% ズーム、`reduce`、JS なしで全文言が読める

### 7.4 性能

- 動かすのは transform・opacity・canvas 描画だけ。filter・マスク位置・clip-path の動き、動く mix-blend 層、スクロール中に変わる属性への `:has()` は使わない
- デスクトップ：写真は `<picture>` の `media="(min-width: 1024px)"` だけで読み込む（モバイルは 1×1 の透明 GIF）。最初のタイル `base-0.webp` と `dim-0.webp` を preload
- モバイル：canvas 用の画像は JS が段階的に読む（ヒーロー → 索引 → 全景 → 下の層）。最初の段の `sky.webp` と `base-0.webp` を preload
- 文書の位置は resize / フォント読込時だけ計測し、スクロール中は読まない
