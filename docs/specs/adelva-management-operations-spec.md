- モバイルの章（写真＋行）は、同じ `<section>`（4章）をモバイル配置で並べ替える。4章の DOM は 1 組だけ持ち、デスクトップでは断面マップ上に、モバイルでは縦並びにする（重複 DOM を作らない）。
