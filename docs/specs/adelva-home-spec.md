## 5. 構成

一つの DOM（`src/components/home-a2/home-page.tsx`）を三つの配置が共有する（`home.module.css`）。

| 配置     | 条件                                                                              | 内容                                                                                            |
| -------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 静止版   | 既定（JS なし・reduce・`(scripting)` 非対応）                                     | 各場面を通常の流れで読む。映像はポスター、課題は 5 か所の静止写真、湖は最後の朝の光、工程は一覧 |
| PC 版    | `(scripting: enabled) and (prefers-reduced-motion: no-preference)` かつ ≥ 1024 px | `A2.html` の 6 場面（sticky ステージ）。`desktop.ts`                                            |
| スマホ版 | 同上かつ < 1024 px                                                                | `A2m.html` の 6 場面と固定の「一本の線」（`[data-spine]`）。`mobile.ts`                         |

場面の長さ（vh）：PC 270 / 420 / 760 / 360 / 330 / 1180、スマホ 280 / 490 / 820 / 400 / 420 / 1220（試作どおり）。

## 6. ヘッダー（`SiteHeader` への追加）

- `src/lib/header-state.ts`：ページから面（`film`・`paper`・`glass`）、ブランドの表示、読み込みの導入を上書きする小さなストア。HOME は場面の境でだけ書く。
- `data-brand="hidden"`（`/` の既定）：巨大な ADELVA がバーへ飛び込むまで（PC p > 0.27、スマホ p > 0.235）ブランドを隠す。motion 許可時のみ、フォーカス時は常に表示。
- `data-intro`：バーを 2.0〜2.6 s でフェードイン（試作の `smooth(2.0, 2.6, t)`）。
- HOME のガラス面：試作のスモークのバー（70%、blur 16px）と下端の線。共通の羽根状ベールは山頂を暗くするため HOME のガラス面では使わない。`data-brand` を持つのは HOME だけなので他ルートは不変。

## 7. 写真と描き直し

`docs/asset-provenance.md` の 2026-10-02 節に全ファイルと出所。要点：

- 72 区画（768×512 → 2 倍）を Codex `gpt-6.1-sol`／`high` が描き直し、Opus が登録（位相相関 + 平滑化した DIS フロー）・トーン合わせ（σ 3 px 以下は採用版）・最小差の継ぎ目で結合（`references/adelva/mockups/home-r3-2x-2026-10-02/tools/merge-tiles.py`）。
- 光の差分（P-1g・P-1s・P-3L）と前景のマットは画素で作る（生成しない）ため、ベースと完全に位置が一致する。
- テクスチャ：PC は 2 倍（パノラマは 6176 px 幅 × 2 枚）、スマホは 1.5 倍（3120 px 幅 × 3 枚、4096 px 上限の GPU 向け）。湖の奥の層は前景が覆わない上部 576 行だけ。
- 遅延読み込み：パノラマは課題の 2.5 画面手前か読み込み後の空き時間、湖は 3 画面手前か空き時間。

## 8. 拡縮規則

- PC：`--k = min(100vw / 1440, 100vh / 900, 1.4px)`。試作の CSS px を `k` 倍。小さな文字は `--kt = max(k, 0.9px)`。JS の距離も同じ `k`。
- スマホ・タブレット：`--m = clamp(0.86px, min(100vw / 390, 100vh / 844), 1.5px)`、小さな文字 `--mt = max(m, 0.95px)`。
- iOS のツールバー：ステージは 100vh（= lvh）で WebGL を安定させ、画面下に寄せる UI は `--gap-b = 100lvh − 100dvh` だけ持ち上げる。高さだけの小さな変化では再計測しない。

## 9. 試作からの差分（すべて意図）

| 差分                                                                                     | 理由                                                                       |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 読み込みの導入（線・映像の開き・文字の立ち上がり）を CSS アニメーションで                | 初回描画から動かし、ハイドレーションのちらつきを防ぐ（式は同じイージング） |
| 映像は分かれるまで `<video>` をそのまま表示し、分かれる間だけ canvas に描く              | 毎フレームの 2 枚描画を避ける。見た目は同じ                                |
| 背景映像の一時停止ボタン（右下・スマホは右上、分かれ始めで消える）                       | WCAG 2.2.2。ラベルは「背景映像を一時停止／再生」                           |
| 3 つの支援領域の番号：紙の上ではインク色＋短いオレンジの線、写真の上では生成り           | オレンジの小さな数字は紙の上で 2.2:1（スマホ試作の修正を PC にも適用）     |
| 文字背後の陰り（課題の見出し・番号・道のり、湖の工程札と一覧、最後の一文とリンク）を濃く | 写真の上の文字を 4.5:1（大きな文字 3:1）以上に（§11）                      |
| 場面は画面から出た時点で描画を止める（試作は 1/4 画面先まで描いた）                      | フッター表示中の無駄な WebGL 描画をなくす                                  |
| スキップリンク「本文へ移動」                                                             | 他の ADELVA ページと同じ                                                   |
