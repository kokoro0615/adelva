## 7. レスポンシブ

| 範囲        | 構成                                                                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ≥1024px     | デスクトップのモック。全寸法を `--u` で比例。1920px 超は 1920 で止めて中央寄せ。本文・タグなど小さい文字は `max()` で下限（12–16px）                      |
| 600–1023px  | モバイルのモックを全幅で比例（写真・枠・線は `--m`）。文字は `--t` でゆるやかに拡大し、文字主体の区間の高さも `--t`。拡大線は幾何が比例するため静的に正確 |
| <600px      | モバイルのモック。390 で全区間の上端がモックと一致                                                                                                        |
| ズーム 200% | CSS 幅が半分になり下位の構成へ移る。文字は `--t` と `max()` の下限で読める大きさを保ち、写真枠は `aspect-ratio` で文字に合わせて伸びる                    |

単位は `container-type` ではなくビューポートから作る：サイズコンテナはレイアウト包含を伴い、ピン留めしたヒーロー（fixed）の包含ブロックになってしまうため。

## 10. モーション（`approach-motion.tsx`）

ふつうの状態変化は CSS。スクロール連動と計測を伴うものだけ GSAP/ScrollTrigger（`useGSAP`、スコープ付き ref、`gsap.matchMedia`、クリーンアップで全スタイルを戻す）。サーバーは完成状態を描き、`prefers-reduced-motion: no-preference` のときだけ巻き戻して演出する。

| 部位                     | 動き                                                                                                                                                                                                                                                                                                        | 値                                                                                    |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| ヒーロー（初回）         | 枠を `stroke-dashoffset` で描き、四隅を置く。写真はファインダー中心へ 1→1.04。レールのオレンジを 01 まで伸ばす。ヒーローの拡大線を置く                                                                                                                                                                      | 1.2s reveal、2s、0.8s                                                                 |
| 潜る                     | ヒーローを `pin`（`pinSpacing: false`）。窓 W をファインダー F0 から 01 の実際の位置 N へ対数補間し、カメラ（ヒーロー写真）は F0 が W になるよう拡大・移動、01 は W を覆うよう一様拡大して `clip-path` で切り抜く（FLIP、終点で変形なし）。文字・CTA・レールは 0–0.36 で上へ抜け、夜の幕は生の進捗で 0.28–1 | scrub 0.4（デスクトップ、Lenis あり）/ 0.5、到着はデスクトップ中央・モバイル上端 96px |
| 工程間の合焦             | 次の写真が画面に入ってから 42% まで、ファインダーの比率の窓（幅 32%）が中央から開き、中の写真は 1.25→1、前のファインダーは 1.08→1。拡大線の終点は窓の上の角を追う                                                                                                                                           | scrub 0.4、すべて transform / clip-path                                               |
| 工程の文字               | 番号→工程名→説明→タグ、8px 下から                                                                                                                                                                                                                                                                           | 300ms、60ms ずつ、一度だけ                                                            |
| 06 引継ぎ                | 生成りの枠を描き、罫線はオレンジ 41.6% → 生成り                                                                                                                                                                                                                                                             | 1.2s、0.6s + 0.6s、一度だけ                                                           |
| 固定の降下レール         | 潜り終えてから 06 まで右の余白に表示。現在の点はオレンジ、通過は生成り、06 で生成りに                                                                                                                                                                                                                       | 装飾（`aria-hidden`）                                                                 |
| 範囲バー                 | `scaleX` 0→1、左から、80ms ずつ。ADELVA は最後に 0.6s                                                                                                                                                                                                                                                       | 一度だけ                                                                              |
| 横断支援                 | 写真の視差（yPercent −5→5、scale 1.1）、線を左→右、タグの角が線の到達順にはまる                                                                                                                                                                                                                             | 0.9s、0.16s                                                                           |
| 確認する内容             | 4 つの印が順に                                                                                                                                                                                                                                                                                              | 300ms、80ms ずつ                                                                      |
| キーボード               | 持ち上げたヒーロー内へフォーカスが戻ると先頭へスクロールして表示を戻す                                                                                                                                                                                                                                      |                                                                                       |
| reduced motion / JS なし | 何も登録しない。モックと同じ静止状態                                                                                                                                                                                                                                                                        |                                                                                       |

## 12. キャプチャ

`scripts/adelva/capture-approach.mjs`：専用ポートの本番ビルド、Chromium、DPR 1、`reducedMotion: reduce`、フォントと画像のデコードを待ち、Next の開発オーバーレイを隠す。1440×900、768×1024、390×844 の全ページと最初の画面。

## 13. アクセシビリティと性能

- 見出しは h1 → h2（区間）→ h3（工程・確認項目）。工程は `ol`、役割は `dl`、タグは `ul`。
- ファインダーはすべて次の工程へのリンクで、名前は「02 判断へ」。見た目の枠が小さくても 44px のターゲット。
- 写真の代替テキストは縮尺が分かる説明（工程 01–06）。ヒーロー・横断支援・背景は装飾。拡大線・レール・バー・点は装飾。
- フォーカスは 2 色のリング。キーボードで全リンクに到達でき、固定の要素はフォーカスを奪わない。
- CLS：すべての画像と写真枠に寸法（`aspect-ratio`）。LCP：ヒーローを media 別に preload。
