### 8.2 状態の持ち方

- 課題の選択は `input[type=checkbox]` が唯一の状態。田が灯る・札の文字色・03 の関係する行・07 のチップは CSS の `:has(:checked)` で表示する（JS なしでも動く）。

- JS は、選択トレイ（件数・表示・読み上げ）、水位計の現在地、モバイルの章シート、スクロール演出だけを持つ。

### 8.4 水位計

- デスクトップ（≥ 1024）: `position: fixed; top: 168px; right: 0`。スクロール 0〜ヒーローの間は7項目すべてを表示（モックどおり）。ヒーローを過ぎると、現在の章の名前と目盛りだけを残し、他の名前は透明に（`--dur-panel`）。水位計に hover / focus-within で全項目を表示。各項目は章へのリンク（押せる範囲 24px 以上）。
- < 1024: 右端の細い目盛り（34×372、上端 250）と現在の章の縦書き。全体が `button`（「章の一覧を開く（現在：…）」）で、押すと下からのシート（`dialog`、`showModal`、Escape・背景で閉じる、閉じたら button にフォーカスを戻す）に7章のリンク。
