## 実装時の確定値（初期仕様に対する測定調整）

- H1 は 87u、上端の CSS top は363u。最終字面は参照694pxに対して683px（−1.59%）。
- 写真背後を実測し、desktop map の55%ストップを30%→50%、透明終点を58%→65%へ延長。
  工程右スクリムは72%を0–28%、34%で透明へ。未到達番号は #aeb2bb へ上げ、4.5:1を確保する。
  スクリムの下限は下げず、写真ファイルは変更しない（指示書のAA調整許可）。
- モバイル英字は12px下限を保って字間を .27em にする。小さなラベルと工程タグも12px下限。
  比較19の説明、工程06タグは必要な折り返しを許す。比較面13のラベルは枠内に収める。
- モバイル関連カードは指定の350×340 CSSを優先。上端65px、2枚目416px。
  参照の不均等な写真箱とは下辺が最大12px異なる。文字の上端は比較許容差内に揃える。
- 終端はCSSスクロールの丸め0.5px以内を吸収して全passedへ移す。
  matchMedia解除時は元のinline styleを復元し、モバイル部屋枠の位置指定を保持する。
- インク比較ではアンチエイリアスによる1–3pxの分断を同じ行に統合する。
  通過・現在の白文字はRGB最小165超、未到達の灰文字は140超を両画像に同条件で使用する。
  写真部分を誤検出しないよう、カードの文字域はカードごとに分ける。位置の許容差は変更しない。
- コントラストは文字を黒／白で描いた差分から被覆率50%以上の字画を選び、文字だけ透明にした
  実背景で最小値を測る。タグ背景、写真、スクリムを保持し、視覚的に隠した見出しは除外する。
- 写真の寸法予約に加え、日本語2書体と共通ロゴの既存Oswaldを当該ルートでpreloadする。
  フォント切替による初回CLSを抑えるためで、共通ヘッダーやフォント原本は変更しない。
