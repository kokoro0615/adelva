## 8. モーション

共通：ふつうの状態変化は CSS。計測を伴うスクロール演出だけ GSAP/ScrollTrigger（`useGSAP`、スコープ付き ref、`gsap.matchMedia()`、クリーンアップ）。
`[data-motion="on"]` は JS が `prefers-reduced-motion: no-preference` で付ける。文字と操作部分は最初から DOM にあり、演出の完了を待たせない。自動で動き続ける要素はない。

| #   | 部位                   | 動き                                                                                                                                                                                            | 値                                                                                                                                                                                                        |
| --- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M1  | 読み込み（CSS のみ）   | 区間 A のプレートが右上→左下の斜めのマスクで現れる（稜線→杉→屋根）。見出しは行ごとに 8px 下から、リードは後から                                                                                 | マスク 1400ms `--ease-reveal`、遅延 150ms。見出し 400ms、120ms ずつ。`@media (prefers-reduced-motion: no-preference) and (scripting: enabled)` のときだけ。初回描画から始まるので JS の到着でちらつかない |
| M2  | 3 つの願い             | 行が画面の 78% に入ると、行末の点 → 引き出し線 → 丸（2 本の鉛筆線）の順に描かれる。一度だけ                                                                                                     | 点 150ms、線 300ms、丸 600ms（`power2.inOut`）、行ごとに 80ms                                                                                                                                             |
| M3  | 実装の前線（固定区間） | 区間 B を CSS `position: sticky` で固定し、スクロール量 140svh（モバイル 110svh）の間、池の手前の線画が、右上から左下へ進む「にじみの前線」で実写に変わる。前線の縁は朝の光でわずかに温かく光る | WebGL（2 枚の画像：線画版・実写版、ノイズで揺らぐ前線、変化量に比例した光）。ScrollTrigger `scrub: 0.8`。画面に近づいたら読み込み、フレームは変化があるときだけ描く。DPR 上限 1.75                        |
| M3a | 支援領域の丸           | 3 行が画面の 70% に入ると、行の右端の点 → 引き出し線 → 丸が描かれる。前線が丸に近づくと丸が太くなり、対応する行に橙の罫線が付く。前線が通り過ぎると丸と線は薄れて消える（引継ぎ）               | 描画は M2 と同じ値。前線との距離で状態を計算（毎フレーム、変化時だけ DOM に書く）                                                                                                                         |
| M4  | 縮尺バー               | 01→05 が左から（モバイルは上から）塗られ、06 は輪郭のまま                                                                                                                                       | 各 `scaleX`/`scaleY` 0→1、400ms、120ms ずつ。一度だけ                                                                                                                                                     |
| M5  | 表題欄                 | 外枠（上・左）→ 内側の罫線が引かれ、項目が上から順に現れる。署名は本番 `FounderSignature` の描画                                                                                                | 罫線 800ms、項目 60ms ずつ。一度だけ                                                                                                                                                                      |
| M6  | ヘッダー               | 紙の上では墨色。スクロールすると紙のすりガラスの下地                                                                                                                                            | `data-surface="paper"`、`--dur-state`                                                                                                                                                                     |

固定区間の条件：デスクトップは `min-aspect-ratio: 1440/1230`、モバイルは `min-aspect-ratio: 390/1340`（区間が画面より短いと空白が見えるため）。条件外や WebGL が使えないときは固定せず、前線はプレートのまま。
固定中の見え方：`top = min(0, 100svh − (Y下端 − 区間上端) × 単位)`（デスクトップ Y下端 3080、モバイル 3150）。1440×900 では 2180–3080、390×844 では 2306–3150 が見える。

## 10. アクセシビリティ（WCAG 2.2 AA）

- 見出し：H1 1 つ、章は H2（役割・3つの支援領域・支援スタンス・会社概要）、対象者は H3。会社概要は `<dl>`。
- 索引は `<nav aria-label="このページの章">` のページ内リンク。押せる範囲 24px 以上（SC 2.5.8）、モバイルは縦書き。
- 支援領域の 3 行は各領域ページへのリンク（行全体がクリック範囲、44px 以上）。対象者パネルはリンク。問い合わせボタンは `/contact`。
- 鉛筆の丸・引き出し線・枠・署名・プレート・前線のキャンバスは `aria-hidden`。
- 文字の背後の最小コントラスト：本文 4.5:1、大きい文字 3:1 を実測（§11）。
- `prefers-reduced-motion: reduce` で固定・前線・描画をしない。キーボードの focus-visible はグローバルのリングを使う。
